## About

I'm a **Computer Science undergraduate at MIT Manipal** interested in building practical software and understanding the systems behind it.

My work spans AI and data-driven applications, computer vision research, networking, and core software engineering. I enjoy taking an idea from fundamentals to a working implementation—and learning from every iteration.

**Current interests:** Data Structures & Algorithms · AI / ML · Computer Vision · Networking · Systems

> Understand the why. Build the thing. Improve it.
