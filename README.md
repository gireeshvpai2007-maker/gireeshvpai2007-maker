## 📊 Featured project

### [InsightAI — AI-powered business analytics](https://github.com/gireeshvpai2007-maker/InsightAI)

An analytics prototype for exploring tabular data, performing EDA, evaluating regression models, and presenting results through a Streamlit dashboard.

- **Experiment:** house-price regression with Linear Regression (R² 0.8993; MAPE 5.31%).
- **Workflow:** preprocessing → EDA → model evaluation → prediction/dashboard.
- **Stack:** Python, Pandas, NumPy, scikit-learn, Streamlit.
