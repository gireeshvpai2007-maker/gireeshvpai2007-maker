## 👋 About me

I’m a Computer Science undergraduate at **MIT Manipal**, interested in software engineering, AI, data analytics, and the systems that make software work.

I like connecting fundamentals with practical builds—from data structures and digital logic to analytics dashboards, networking experiments, and computer-vision research.

> **My approach:** Understand the why. Build the thing. Improve it.
